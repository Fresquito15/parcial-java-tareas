Parcial Práctico – Desarrollo de Software II
Instrucciones
Clona este repositorio.

Crea una rama llamada fix/parcial-[tu-nombre].

Corrige los errores del código para que todas las pruebas unitarias pasen.

Agrega al menos una prueba unitaria nueva que cubra un caso no probado.

Configura un pipeline de CI (Jenkins o GitLab CI) que compile y ejecute las pruebas.

Haz commit y push de tus cambios.

Abre un Pull Request hacia main con una descripción clara.

Entregable
Enlace al Pull Request.

Evaluación
Uso de Git y ramas: 10%

Corrección de errores: 20%

Pruebas nuevas: 15%

Pipeline de CI: 20%

Pull Request: 15%

Defensa oral: 20%
